### The method

**[The Streanga Method](https://github.com/Mihai-Streanga/streanga-method-for-claude)** is a
complete way of building software with Claude. It runs in claude.ai, where ideas are researched
and decided, and in Claude Code, where they are built, verified and maintained. It has a path for
new projects and one for existing projects. It is measured on six projects, the method itself
being the sixth:

- session start-up cost cut by 61–75%, and long sessions kept lean by a measured ceiling;
- an automated test suite in every project, including 410 tests on the payroll engine;
- a quality review whose findings were fixed in the products the same day;
- a method that improves itself: ten versions in ten days, each driven by the projects' reports.

### How I build
- **Auditable results**: figures come from deterministic code, not from a model.
- **Privacy by design**: sensitive data stays local; no AI model sees real payroll registers.
- **No silent errors**: when a component can't decide, it says why instead of guessing.
- **Tested**: every project ships with automated tests and documented decisions.
- **Measured**: cost, tests and quality are measured, and decisions are made on the numbers.
